# Shafran — сайт ресторана

Одностраничный сайт ресторана восточной кухни: атмосфера заведения, меню,
галерея и онлайн-бронирование столика.

Чистый HTML5 / CSS3 / JavaScript — без фреймворков, сборщиков и внешних
библиотек. Шрифты и изображения лежат локально, поэтому страница работает
и без интернета (кроме встраиваемой карты).

## Структура проекта

```
portfolio/
├── index.html              разметка всех секций
├── assets/
│   ├── css/
│   │   ├── fonts.css       локальные @font-face (Cormorant Garamond, Inter)
│   │   └── style.css       основная таблица стилей
│   ├── js/
│   │   └── main.js         навигация, табы меню, галерея, форма, карта
│   ├── fonts/              woff2, подмножества latin + cyrillic
│   ├── img/                webp-изображения + файлы логотипа
│   ├── favicon.svg
│   └── apple-touch-icon.png
└── README.md
```

## Логотип

Фирменный знак — веточка с тремя листьями, отсылка к растению шафрана.
Он собран в вектор и лежит в нескольких вариантах:

| Файл | Когда использовать |
|------|--------------------|
| `assets/img/logo.svg` | горизонтальный логотип: знак + «SHAFRAN» + дескриптор |
| `assets/img/logo-stacked.svg` | вертикальный вариант — для узких мест и печати |
| `assets/img/logo-mark.svg` | только знак, золотой |
| `assets/img/logo-badge.svg` | знак в зелёном круге — аватар в соцсетях |
| `assets/img/logo-mono.svg` | одноцветный знак на `currentColor` — для печати и тиснения |
| `assets/favicon.svg` | иконка вкладки |
| `assets/apple-touch-icon.png` | иконка 180×180 для домашнего экрана iOS |
| `assets/img/og-image.jpg` | карточка 1200×630 для соцсетей и мессенджеров |

`logo.svg` и `logo-stacked.svg` самодостаточны: шрифты Cormorant Garamond
и Inter встроены в файл, поэтому надпись выглядит одинаково везде —
в браузере, в презентации, у типографии. Остальные файлы содержат только
геометрию и весят меньше килобайта.

В самом сайте знак вставлен инлайном (шапка и подвал), чтобы им управлял
CSS: цвет берётся из переменной `--gold`, при наведении знак слегка
поворачивается.

Минимальный размер знака — 20 px по высоте; свободное поле вокруг —
не меньше высоты одного листа.

## Запуск

Достаточно открыть `index.html` в браузере. Для корректной работы карты
и относительных путей удобнее поднять локальный сервер:

```bash
npx http-server . -p 8080
# или
python -m http.server 8080
```

## Технические решения

**Фирменный стиль.** Палитра вынесена в CSS-переменные в начале
`style.css`:

| Переменная      | Значение  | Назначение |
|-----------------|-----------|------------|
| `--ink`         | `#07110F` | основной фон |
| `--ink-soft`    | `#0A1815` | фон чередующихся секций |
| `--green-deep`  | `#0D211B` | карточки, форма, модалки |
| `--green`       | `#174B3A` | активные состояния, акцентные плашки |
| `--gold`        | `#D4AF5A` | акценты, цены, иконки |
| `--cream`       | `#F5F2E9` | основной текст |
| `--muted`       | `#A9B3AD` | вторичный текст |

Заголовки набраны Cormorant Garamond, интерфейс и текст — Inter.

**Производительность.**
- Изображения в WebP, размеры подобраны под место вывода; у всех задана
  ширина и высота, чтобы не было сдвигов вёрстки.
- Hero-фотография грузится с `fetchpriority="high"`, остальные — `loading="lazy"`.
- Отдельный кадр hero для экранов до 640px через `<picture>`.
- Шрифты — вариативные woff2, только latin + cyrillic, с `font-display: swap`
  и preload для кириллических подмножеств.
- Карта OpenStreetMap подгружается только по нажатию кнопки «Показать карту».
- Ноль внешних зависимостей: один CSS-файл со стилями, один JS-файл (~9 КБ).

**Доступность.**
- Семантические теги, единственный `h1`, последовательная иерархия `h2`–`h3`.
- Ссылка «Перейти к содержимому» для клавиатуры.
- Табы меню реализованы по паттерну ARIA Tabs, работают стрелками, Home и End.
- Модалка и лайтбокс: `role="dialog"`, `aria-modal`, удержание фокуса,
  закрытие по Esc, возврат фокуса на вызвавший элемент.
- У всех изображений осмысленный `alt`, у иконок — `aria-hidden`.
- Ошибки формы озвучиваются через `role="alert"` и `aria-invalid`.
- Видимый фокус, цели нажатия не меньше 44×44 px.
- `prefers-reduced-motion` отключает анимации и плавную прокрутку.

**SEO.** Заполнены `title`, `description`, Open Graph с собственной
карточкой 1200×630 и canonical, добавлена микроразметка Schema.org
`Restaurant` с адресом, телефоном, часами работы, логотипом
и `acceptsReservations`.

**Адаптивность.** Контрольные точки: 1100px (сетка меню в две колонки),
900px (бургер-меню, одноколоночные секции), 640px (мобильная раскладка,
карточки в колонку, горизонтальный скролл табов, кнопки на всю ширину).

## Форма бронирования

Валидация на стороне клиента: имя, телефон с маской `+7 (999) 999-99-99`,
дата (от сегодня до +90 дней), время и количество гостей. Слоты времени
генерируются с шагом 30 минут с 10:00 до 21:30; для сегодняшней даты
прошедшее время скрывается, а если свободных слотов не осталось —
подставляется ближайший доступный день.

Отправка на сервер не выполняется: в `main.js` в обработчике `submit`
показывается экран успеха. Точка интеграции с бэкендом или CRM отмечена
комментарием в коде.
